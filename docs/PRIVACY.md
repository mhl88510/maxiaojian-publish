# 隐私与运行安全

仓库和 npm 归档使用显式文件白名单。无原生产 Git 历史、登录态、真实账号配置、业务素材、执行日志和历史回执。例子均为虚构。检测已知私人路径、常见凭据字面量、symlink、归档越界及非文本负载；模式扫描无法证明所有未知形式的秘密都不存在，另有逐文件独立审查。

不要提交私有账号矩阵、媒体、api 配置、浏览器 profile 或运行账本。默认账本与配置使用本工具独立目录，不重用原版生产目录。只在自己的登录会话和目标上运行，凭据不放命令行。权限/验证码/用户控制需要本人处理，不能绕过。

真实上传、草稿及发表是软件功能。--execute 是调用者对此次写操作的明确选择，账号校验、媒体校验、一次提交和未知结果先对账仍生效。没有 --execute 不进入原调度写分支。第三方直接绕过 CLI 调用低层模块时须遵守同等业务授权，不以包外修改代码作为保护保证。

CLI 结果会包含安装者自己的账号标识、作品 ID 和本机状态路径。分享输出、报错或回执前应自行脱敏。
