# 平台能力与验收边界

所有下列原生入口已恢复调用能力，保留原版保护。用户已确认原版测试并持续使用；此处不要求重跑原版全平台测试。独立分发版本只做提取/配置/离线回归，没有新发行版的真实发帖证据。

| 平台 | 分发代码与使用路径 | 原版证据能支持到的阶段 / 限制 |
| --- | --- | --- |
| 抖音 | ego_video：检查、上传准备、指定 PREPARED 最终发布、回读 | 历史精确作品 ID 发表/回读；当前账号仍需准确绑定 |
| 小红书 | ego_video：准备、最终发布、回读 | 历史准备 READY；部分历史回读只有内容找到、状态未知，不能统一声称公开确认 |
| 视频号 | ego_video：准备、最终发布、回读 | 历史 READY、指定作品 ID 发表；固定业务续传救援不分发 |
| Bilibili | ego_video：准备、最终投稿、回读 | 历史 READY；新包未真实投稿 |
| YouTube | v2 原版上传/编辑准备，默认最终按钮防护 | 原版历史 READY；统一最终发布后端未覆盖 YouTube，不能用主入口承诺最终发表 |
| 知乎 | ego_article + 安装者 pageContract，原生提交/回读 | 历史发表及修改；已有文章编辑页仍被原保护拦截 |
| 搜狐、头条 | ego_article 原生准备、提交和回读 | 历史发表/送审和回读；固定某篇任务恢复及历史重试链排除，正常新任务可用 |
| 百家号 | 原有内容策略；nativeTrialContract v1 特定原生试验路径 | 历史发表后账号限制属于旧环境；通用文章写入仍保持原版未验证阻断 |
| 网易号 | 管理/回读代码 | 历史审核中；通用文章写入仍按原版阻断 |
| 微博 | ego_weibo_text 原生文本提交和回读 | 原版实现保留；未定位独立的历史发表回执，不能补称实测 |
| 微信公众号 | wechat_api 草稿、发布、状态；原生 UI 模块也保留 | 历史 API 发表/正式文章读取；依赖安装者的外部 Baoyu/AWS 微信工具链和 IP 白名单，非开箱即用 |

视频需要真实可解析媒体、ffprobe、已完成的视频配置，以及新包自己的准备状态。文章需要当前平台原生控件和选项符合原合同；知乎需自己的 selector 合同。账号不明确、登录过期、目标变动时停止。个人专用固定案例、单篇救援、历史材料和私有授权不迁移；使用自己的通用账号 key。

本次测试：原适配器的身份、素材、封面、最终按钮与原调度器用合成对象验证；另测可执行 CLI、明确 opt-in、预约留存和公众号参数化。此类证据与原版真实使用分开，不表示本次运行过真实发布。macOS/本机 Node 是实际运行环境，离线 OS/Node 矩阵结果见 [GitHub Actions](https://github.com/mhl88510/maxiaojian-publish/actions/workflows/offline.yml)，它不等于 Linux/Windows 的真实浏览器发布验收。

已恢复不绑定单篇内容的原版同任务恢复模块：抖音 pristine preflight / input-missing 验证、视频权限中断、视频号 preflight / existing-blob / ready-source-proof、小红书 empty-input / rights-preflight、微博已证实未提交的点击遮挡恢复。文章续传入口先校验同账号、内容哈希、原始路径、未尝试提交的 typed PREPARATION_BLOCKED 回执，随后原生后端仍按原版精确错误类型和编辑器回读再次拒绝或放行；这不是任意草稿都可续发。搜狐原版封面准备失败及 SHA 绑定的配图视觉复核合同保留；头条历史某篇草稿续发和多层救援不能作为通用能力承诺。新文章使用直接 publish 工作流。固定窗口迁移、个人视觉合同、准备 scope 的旧任务特例以及具体文章的人工复核恢复仍明确排除，不能用占位数据承诺支持。
